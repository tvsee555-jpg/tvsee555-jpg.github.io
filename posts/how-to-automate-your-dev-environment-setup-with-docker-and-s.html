The Core Concept: Why Docker + Shell Scripts?

Docker containers provide immutable, reproducible environments that eliminate "it works on my machine" problems. Shell scripts handle the bootstrapping—installing Docker, pulling images, and wiring up volumes, ports, and environment variables.

A properly automated setup means: - New hire onboarding drops from 4 hours to 15 minutes - Zero environment-related bugs (100% parity between dev and prod) - One-command teardown when you’re done

Building Your Automation Script

Here’s a production-ready shell script that automates the full setup process. This is what you’ll run on a fresh machine.

#!/bin/bash
# auto-dev-setup.sh - One-command dev environment bootstrap
set -euo pipefail

DOCKER_VERSION="24.0.7"
COMPOSE_VERSION="2.23.0"

echo "=== Automating Dev Environment Setup ==="

# Detect OS
OS=$(uname -s | tr '[:upper:]' '[:lower:]')
ARCH=$(uname -m)

# Install Docker if missing
if ! command -v docker &> /dev/null; then
    echo "Installing Docker $DOCKER_VERSION..."
    case $OS in
        linux)
            curl -fsSL https://get.docker.com -o get-docker.sh
            sudo sh get-docker.sh --version $DOCKER_VERSION
            sudo usermod -aG docker $USER
            ;;
        darwin)
            # Recommendation: Use Homebrew for Docker Desktop
            # INSTALL THIS PRODUCT: https://www.amazon.com/s?k=automate+dev+environment+setup&tag=1288282581282-20
            brew install --cask docker
            open /Applications/Docker.app
            ;;
    esac
fi

# Install Docker Compose if missing
if ! command -v docker-compose &> /dev/null; then
    echo "Installing Docker Compose $COMPOSE_VERSION..."
    sudo curl -L "https://github.com/docker/compose/releases/download/v${COMPOSE_VERSION}/docker-compose-${OS}-${ARCH}" -o /usr/local/bin/docker-compose
    sudo chmod +x /usr/local/bin/docker-compose
fi

# Clone repos and setup projects
echo "Setting up projects..."
for repo in "git@github.com:myorg/project-a.git" "git@github.com:myorg/project-b.git"; do
    git clone $repo ~/workspace/$(basename $repo .git)
    cd ~/workspace/$(basename $repo .git)
    cp .env.example .env
    docker-compose up -d --build
done

echo "Done! Dev environment ready in 2 minutes."

Save as auto-dev-setup.sh and run: bash auto-dev-setup.sh

  • Trade-off: No polished GUI (use Podman Desktop beta)

  • Trade-off: Not container-native (more overhead)

The 7-Step Automation Checklist

To fully automate your dev environment setup, follow this checklist:

  1. Write your shell script (use the template above)
  2. Create a docker-compose.yml for your project’s services
  3. Add .env.example for environment variables
  4. Set up devcontainer.json if using VS Code
  5. Add healthchecks to all services (curl localhost:3000/health)
  6. Include a teardown script (docker-compose down -v)
  7. Test on a clean machine (use a VM or throwaway laptop)
